## ⚡ Command Sequence

### 1️⃣ Generate Vocabulary (One-time)
```bash
python vocabulary_generator.py \
    --csv gridcorpus/mouth_data_context.csv \
    --output vocabulary.json \
    --validate
```
**Output:** `vocabulary.json` (55 tokens: 53 words + <START> + <END>)

---

### 2️⃣ Train Model
```bash
# Basic (uses defaults)
python train.py

# Custom configuration
python train.py \
    --epochs 50 \
    --batch-size 64 \
    --lr 1e-3 \
    --model-type transformer \
    --embedding-dim 128 \
    --num-heads 8 \
    --num-layers 4
```

**Output:** 
- `checkpoints/best_model.pt` ← Best validation loss
- `logs/run_XXX/` ← TensorBoard metrics

---

### 3️⃣ Monitor Training (in separate terminal)
```bash
tensorboard --logdir logs
# Open: http://localhost:6006
```

## 🎯 Input/Output Formats

### Vocabulary.json
```json
{
  "word_to_id": {
    "<START>": 0,
    "a": 1,
    "again": 2,
    ...
    "zero": 53,
    "<END>": 54
  },
  "id_to_word": {
    "0": "<START>",
    "1": "a",
    ...
  },
  "vocab_size": 55,
  "unique_words": 53,
  "special_tokens": ["<START>", "<END>"]
}
```

### Model Batch Input
```python
batch = {
    'prev_word': torch.LongTensor([0, 5, 12, ...]),        # shape: (64,)
    'curr_word': torch.LongTensor([3, 7, 14, ...]),        # shape: (64,)
    'next_word': torch.LongTensor([8, 11, 2, ...]),        # shape: (64,)
    'frame_pos': torch.FloatTensor([0.3, 0.7, 0.1, ...]),  # shape: (64,)
    'word_duration': torch.FloatTensor([0.4, 0.6, 0.2,...]) # shape: (64,)
}
```

### Model Output
```python
blend_shapes = model(batch)  # shape: (64, 52)
# All values in range [0, 1]
# Each row: 52 blend shape values for one frame
```

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| **OOM Error** | `--batch-size 32` or `--embedding-dim 64` |
| **Loss not decreasing** | `--lr 5e-4` or check data loading |
| **Overfitting** | Increase dropout in model.py to 0.3 |
| **Slow training** | Reduce `--num-layers 2` or use smaller dim |
| **Memory usage high** | Reduce `num_workers=2` in dataloader.py |
